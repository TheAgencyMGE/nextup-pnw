Ten for Teaching: Facilitating effective classroom engagement and interactions (ASYNCHRONOUS)

Boise State University Events

Cooperative learning, wherein students are learning with and from one another, has been shown to support learning. Creating an interactive learning environment that supports all learners must be done intentionally though. In this workshop, we will talk about how to begin building that community, how to facilitate activities and create more engaging discussions, and how to use questions more strategically during class. Participants will also learn strategies for more effective group work as well as how to navigate classroom conflict.
