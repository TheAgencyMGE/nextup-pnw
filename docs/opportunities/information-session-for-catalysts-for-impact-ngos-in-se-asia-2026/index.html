Information Session for Catalysts for Impact: NGOs in SE Asia

University of Oregon Events

Interested in learning about nonprofit and nongovernmental organizations (NGOs) in Southeast Asia? Join the information session for Catalysts for Impact: NGOs in SE Asia to learn about the NGO sector, explore issues affecting the region, and discover how you can gain hands-on experience working on a project for a local organization in Cambodia. We’ll cover program details, travel locations, and application requirements. This event is part of International Education Month (IEM) programming. View the full calendar of IEM events here: https://international.uoregon.edu/IEM .
