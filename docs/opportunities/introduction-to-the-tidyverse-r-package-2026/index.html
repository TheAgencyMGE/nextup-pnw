Introduction to the tidyverse R package

UBC Library Research Commons

The tidyverse is a collection of R packages designed for data science. All packages share an underlying design philosophy, grammar, and data structures. This workshop presents some of the major tidyverse packages. At the end of the workshop, you will: Know what the tidyverse is Understand the uses of data manipulation packages Know where to look for answers when manipulating your data in R The workshop is 60 minutes long, followed by an optional 30-minute practice period to reinforce what you learned or consult with the instructors.
