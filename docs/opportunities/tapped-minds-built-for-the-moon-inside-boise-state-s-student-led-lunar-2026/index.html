Tapped Minds - Built for the Moon: Inside Boise State's Student-Led Lunar Robotics

Boise State University Events

Looking for an easy way to learn something new and connect with others? Tapped Minds is a monthly Boise State Alumni Association event that brings interesting ideas out of the classroom and into a relaxed, social setting. Join us on the first Monday of each month from 6–7 p.m. at Lost Grove Brewing for an engaging talk from someone in the Boise State community.
