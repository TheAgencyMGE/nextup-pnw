Data Bites – File Naming Best Practices for Research Data

UBC Library Research Commons

Workshop: File Naming Best Practices for Research Data This practical workshop, delivered by the UBC Library Research Data Management team , introduces strategies for consistent and meaningful file naming to support better research organization, collaboration, and long-term data reuse. Designed for graduate students, researchers, and staff, this session helps participants avoid common pitfalls and adopt best practices in their research workflows. Participants will learn how to: Apply clear and consistent file naming conventions Incorporate elements like version control, dates, and identifiers for easy file tracking and retrieval Avoid problematic file names that can cause compatibility issue
