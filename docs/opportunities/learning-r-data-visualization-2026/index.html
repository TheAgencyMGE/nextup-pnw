Learning R: Data Visualization

UBC Okanagan Events

Join us for the R Fundamentals for Data Analysis workshop series! This series of introductory workshops are intended for individuals with little to no familiarity with R or similar tools that rely on a scripted environment. They are intended as a low barrier entry into the world of using your computer to engage with data outside of graphical tools like Excel or SPSS. Data Visualization : This session will introduce ggplot for data visualization. Common visualizations, including bar charts, histograms, scatterplots, etc. will be covered. By the end of this session participants will be able to build, annotate, and customize common data visualizations. REGISTER FOR INDIVIDUAL WORKSHOP Register
