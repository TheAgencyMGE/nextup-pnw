Hyak Klone Slurm Workshop

University of Washington Campus Calendar

Learn how to run jobs effectively on Hyak Klone with this hands-on Slurm workshop on Tuesday October 27, 10:00am–12:00pm. We’ll introduce Klone-specific scheduling options and practice with core Slurm skills, including interactive jobs, batch jobs, and array jobs. This session is designed to help you build confidence in using Slurm for a variety of research workflows on Hyak Klone. Prerequisites - We recommend some Hyak Klone and Linux experience: The Linux Command Line Fundamentals Workshop on Thursday October 15 starting at 10:00am at eScience provides a perfect opportunity to get started using Hyak Klone.
