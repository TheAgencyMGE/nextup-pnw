Learning R: Fundamental Concepts with RStudio

UBC Okanagan Events

Join us for the R Fundamentals for Data Analysis workshop series! This series of introductory workshops is intended for individuals with little to no familiarity with R or similar tools that rely on a scripted environment. They are intended as a low-barrier entry into the world of using your computer to engage with data outside of graphical tools like Excel or SPSS. Fundamental Concepts with RStudio : This session will introduce participants to fundamental concepts in R that will help them excel at more advanced applications. Topics covered include the application of simple math, core data types and structures, an overview of vector operations, and how to navigate getting help. The workshop
