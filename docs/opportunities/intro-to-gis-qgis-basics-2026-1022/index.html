Intro to GIS: QGIS Basics

Oregon State University Events

Need to use geospatial data in your research? Learn how to load tabular, raster, and vector geospatial data, add base maps and other online services, extract relevant data, and author basic maps. In this workshop we'll use QGIS, an open-source software suite compatible with Windows, MacOS, and Linux/UNIX. If you're already familiar with other GIS software this training may be useful to you, but assumes no prior knowledge. NOTE: This workshop is provided via Zoom only; you must install QGIS on your own machine prior to the event to follow along.
