Introduction to Large Language Models (LLMs)

UBC Library Research Commons

This workshop focuses on Large Language Models (LLM) to provide participants with a foundational understanding of LLM, their working, and how to fine-tune a pre-trained LLM for your own data. In this workshop, we will use cloud-based platforms, so you don’t need to have Python installed. Please make sure that you have a Google Colaboratory (https://colab.research.google.com/) account. This workshop will involve hands-on exercises that require the use of programming tools and libraries commonly used in machine learning, such as Python and Scikit-learn.
