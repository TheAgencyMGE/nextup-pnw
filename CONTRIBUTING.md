# Contributing

The easiest contribution is the **Submit an opportunity** Issue Form. Use an official organizer link and include eligibility and date details when available.

Code and source-registry improvements are welcome through pull requests. Before opening one, run:

```bash
python -m unittest discover -s tests -p 'test_*.py'
python scripts/build_static.py
```

Do not add sources that require authentication, prohibit automated access, publish mostly unrelated content, or routinely omit official dates and locations. Do not add scraped personal contact information.
