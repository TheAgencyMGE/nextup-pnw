Using Pressbooks for Open Educational Resource Development (ZOOM)

Boise State University Events

In this interactive workshop, you will learn the basics of how to use Pressbooks for OER creation, including creating and importing content and using H5P to create interactive learning experiences for your students. By the end of the session you will have created at least the introduction to a Pressbook and will be comfortable with creating an Open Educational Resource using the Pressbooks platform. At the end of this workshop, you will be able to: - Create content in Pressbooks - Import content into Pressbooks - Apply licensing principles in Pressbooks - Create interactive learning materials using H5P in Pressbooks --- Event Details: https://boisestate.campusgroups.com/rsvp?id=397161
