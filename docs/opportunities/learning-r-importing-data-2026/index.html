Learning R: Importing Data

UBC Okanagan Events

Join us for the R Fundamentals for Data Analysis workshop series! This series of introductory workshops is intended for individuals with little to no familiarity with R or similar tools that rely on a scripted environment. They are intended as a low-barrier entry into the world of using your computer to engage with data outside of graphical tools like Excel or SPSS. Importing Data : This session will address importing Excel and comma separated value files into R for analysis. Topics covered include variable naming, variable assignment, missing values on import, assigning appropriate data types to variables, and saving data as R data objects.
