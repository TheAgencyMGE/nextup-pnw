TITLE : InventionID: Automated Invention Extraction and Prior-Art Analysis from Technical Documents ABSTRACT : Researchers and university technology-transfer teams often need to review technical papers to determine whether they contain potentially patentable ideas and whether similar prior art already exists. This process can be slow because papers are long, patent-search language differs from research-writing language, and reviewers need both an invention summary and supporting search evidence. In this project, we present InventionID, a web-based prototype that helps identify potentially patentable ideas from technical papers.
