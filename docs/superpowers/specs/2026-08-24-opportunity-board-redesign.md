# NextUp PNW Opportunity Board Redesign

## Product thesis

NextUp PNW is a date-driven directory for students and early-career people around Puget Sound. Its job is to help someone find a credible internship, workshop, fair, competition, or program before the date passes. The interface should feel like a dependable regional schedule: timely, local, direct, and easy to scan.

The primary action is browsing and filtering opportunities. Opening the official organizer page is the primary action on a listing. Submitting a missing official link and reading the methodology are secondary actions.

## Visual direction

Use a schedule-first “PNW opportunity board” rather than a marketing landing page.

- **Palette:** Fog `#f2f4f0`, Paper `#ffffff`, Evergreen `#12372a`, Ink `#17211c`, Lichen `#dbe8b3`, Signal `#df5a3c`, Line `#bcc6be`, Muted `#5d6b63`.
- **Typography:** condensed sans-serif for display headings, humanist system sans-serif for body copy, and monospace for dates and compact metadata. No remote font dependency.
- **Layout:** compact introduction and filters in the first viewport; chronological agenda rows with a date rail; restrained methodology and submission sections; content-first detail pages.
- **Signature:** each listing reads like an entry on a regional departure board, with a strong date marker and a consistent route from title to official link.

The `N↗` mark, evergreen regional identity, real listing count, filtering, direct official links, and “Stop finding out after it happened” line remain. The tagline moves into a supporting role rather than acting as an oversized marketing headline.

## Homepage structure

1. A compact header with the brand, directory anchor, methodology anchor, and “Send an official link.”
2. A left-weighted introduction that says what the directory contains and where it applies.
3. A live directory toolbar with text, location, field, and beginner filters plus a clear reset action.
4. A chronological list. Each row exposes date, title, organizer, description, field, location, type, cost, eligibility, verification date, and a specific “View official listing” action.
5. A concise methodology strip describing source collection, checks, and expiry behavior without decorative numbered cards.
6. A restrained submission section asking for an official organizer link.

## Detail pages

Detail pages use the same header and tokens. The title and organizer lead. Date and key facts form a stable information rail. Eligibility, description, and “why it matters” remain readable in the main column. “Open official listing” is the dominant action.

## Copy

Copy is factual and student-facing. Remove vague claims such as “opportunities worth showing up for,” ceremonial eyebrows, fake urgency, and generic “community powered” language. Keep specific facts: number of active listings, covered region, source verification, and direct organizer links.

## Responsive and accessibility requirements

- No horizontal overflow at 320, 390, 768, 1024, or 1440 CSS pixels.
- At narrow widths, filters become a two-column layout and then a single-column form; agenda rows recompose without hiding required information.
- Semantic headings, labels, links, visible focus, 44px touch targets where practical, and sufficient contrast are required.
- Filters remain keyboard accessible and the empty state includes a working reset action.
- Motion is limited to direct hover/focus feedback and is disabled with `prefers-reduced-motion`.

## Rendering consistency

`app/page.tsx` and `static/index.template.html` must expose the same content hierarchy. `app/globals.css` remains the shared visual source; `scripts/build_static.py` copies it into `docs/assets/styles.css`. Static cards generated by `scripts/build_static.py` must use the same agenda-row structure as React.
