Jump Start

UBC Okanagan Events

Jump Start is a multi-day enhanced orientation designed to give new-to-UBCO students the opportunity to learn about support resources on campus, build a sense of belonging at UBCO and in Kelowna, warm up your academic skills, get organized before university starts, access services, and meet other students. Join us September 3 to 7 when we’ll be hosting workshops and activities to set participants up for academic success while helping them to find community at UBC and get set up for the year ahead. We encourage new-to-UBCO students to register as soon as possible so that they can get earlier access to our Jump Start app so they can build and view their own personalized program schedule. Jump
