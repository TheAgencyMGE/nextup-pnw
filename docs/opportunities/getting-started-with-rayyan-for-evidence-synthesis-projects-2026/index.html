Getting Started with Rayyan for Evidence Synthesis Projects

Oregon State University Events

Learn the basics of getting Rayyan set up and running to manage an evidence synthesis project. In the workshop, participants will set up a review, get records into the review, set up screening parameters, and look at data extraction functionality. Since Rayyan is primarily a fee-based tool, we’ll level the playing field by using only the options in the free version of Rayyan. Participants must register for a Rayyan account to actively participate in the session exercises; participants new to Rayyan do not need to set up a trial review in advance of the session. This session will be held remotely over Zoom. Registration is required, and Zoom links and passwords will be emailed to registrants.
